# Course of Fire – Beta Feedback

Thanks for testing the Course of Fire app! This repository is where beta testers report bugs and suggest features. The app's source code is kept private; only feedback lives here.

## How to give feedback

1. Go to the **[Issues](../../issues)** tab.
2. Click **New issue**.
3. Choose **Bug report** or **Feature request** and fill in the form.

You'll need a free GitHub account to open an issue.

## Before you report

- Search the existing issues first; if someone already reported it, add a 👍 or a comment instead of opening a duplicate.
- One problem or idea per issue.
- Screenshots and screen recordings help a lot.
- Please don't post personal information.

## Can't use GitHub?

That's fine. Use the feedback option on the Google Play testing page instead.
